# OOP Calculator

This project is an object-oriented calculator built in Python. It demonstrates important object-oriented programming concepts.

## Features

The calculator supports the following commands:

- `add` - Add two numbers
- `subtract` - Subtract two numbers
- `history` - Display calculation history
- `remove` - Remove a calculation from history
- `help` - Display available commands
- `exit` - Exit the calculator

## Running the Calculator

Run:

```bash
python main.py
